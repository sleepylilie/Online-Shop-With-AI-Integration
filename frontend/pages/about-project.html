Что это за проект и с чем его едят

Это - проект выпускной квалификационной работы электронного магазина товаров творчества и хобби. Интернет-магазин представляет из себя готовую модель с настроенной базой данных, а также страницей административного управления. Пользователям предоставляется возможность собрать свою корзину, оформить заказ и прочие функции, за исключением непосредственной оплаты и отправки заказов.

Для интернет-магазина была придумана уникальная функция: интеграция искусственного интеллекта для генерации творческих идей. Таким образом можно увеличить обороты магазина и предоставить пользователям полезный инструмент на случай, если им нужно вдохновение.

В базу данных были загружены тестовые данные, сгенерированные искусственным интеллектом DeepSeek для проверки работы, поэтому есть возможность перемещаться по сайту, взаимодействовать со всеми кнопками.

Этапы разработки проекта

Для полноценной разработки нужно было разработать:
1. Базу данных;
2. Frontend;
3. Backend.

База данных была создана с помощью PostgreSQL. Были добавлены все необходимые таблицы с данными. Для Frontend был сделан прототип интерфейса в Figma. Далее прототип был перенесен с помощью HTML+CSS, для динамических взаимодействий интерфейса использован Typescript. Backend реализован с помощью Django, который предоставляет средства для администрирования и создания собственного API.
